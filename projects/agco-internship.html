Weather Station UI & CAN Signal Routing

Two summers as an Embedded Software Engineering Intern at AGCO in Jackson, MN, working on the RoGator sprayer platform: leading the UI and CAN signal routing for an integrated weather station system, plus optimization and calibration software.

RoleEmbedded Software Engineering Intern
TimelineJun 2024 – Aug 2024; Jun 2025 – Aug 2025
ToolsC/C++, CAN bus, CANalyzer
01

The Problem

The RoGator sprayer platform needed an integrated weather station system — sensor data had to be routed over CAN and surfaced to the operator through a usable interface, and several existing tools/processes were slow enough to bottleneck development.

02

What I Built

Led the design and implementation of the UI and CAN signal routing for the integrated weather station system on the sprayer platforms, and built calibration software for the RoGator sprayer tractor. Delivered up to 200x faster runtimes across four separate optimization projects.
